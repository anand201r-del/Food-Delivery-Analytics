Food Delivery Live

A portfolio project by Anand Kumar (M.Tech CSE, IIIT Guwahati): MySQL schema, stored procedures, triggers and indexes, a Python order simulator, a FastAPI backend and an AI analyst.

Orders, customers and restaurants are simulated. The rainfall is real (Open-Meteo). Not affiliated with Swiggy or Zomato. AI answers can be wrong; check the SQL shown with each answer.
